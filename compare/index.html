Equipment list compare

Paste two revisions of an equipment list and get a plain log of what was added, removed or changed. Lines for the same item are added up first, and the result is grouped by location and system. Everything happens in this page: nothing is saved, uploaded or sent anywhere. Works offline.

1. The two lists

In Excel, select the cells including the row of column headings, copy, and paste into the box. Or load a .csv file. Excel workbooks (.xlsx) and PDFs are not read directly.

How lines are matched

  • Column headings. The first row with two or more filled cells is taken as the column headings. Anything above it (a title line, for example) is ignored. Columns that are not picked in step 2, such as prices or notes, are ignored too.
  • Heading rows. A row with text in only one cell is a heading, and every line under it belongs to that heading until the next one. A heading directly followed by another heading is read as a location and then a system inside it; a single heading after that is another system in the same location. If headings never come in pairs, every heading is a location. If the list has Location or System columns, those are used and one-cell rows are treated as ordinary lines.
  • What makes two lines the same item. The model number. If the line has no model number, the part number. If it has neither, the description. Only columns that both lists have are used, so if just one list has model numbers, matching falls back to the part number. The manufacturer is part of the match when both lists have a manufacturer column. Capitals and extra spaces are ignored: "cm-40 " and "CM-40" are the same.
  • Where. Lines are only compared inside the same location and system, matched by the heading text. An item that moves from one room to another shows as removed in one and added in the other.
  • Renamed rooms or systems. "Board Room 201" and "Boardroom 201" are different text, so they are treated as different places. When a heading is in only one list, step 2 offers a drop-down to say which heading in the other list it is the same as. The tool never decides this itself. The log states each rename you chose.
  • Duplicate lines. When the same item is on several lines in the same location and system, the quantities are added together first, and the log says how many lines were combined.
  • Quantity. Qty B minus Qty A. "2.0" is 2. A blank quantity counts as 1. A quantity that is not a number (such as "TBD") also counts as 1, and step 2 lists the rows where that happened.
  • Changed. The same item with a different part number, manufacturer or description. A column is only checked when both lists have it.
  • No guessing. A replaced item shows as one removed line and one added line. The tool does not decide that one replaced the other.
  • Nothing dropped silently. A line with no model number, part number or description cannot be matched. It is listed under the log with its row number.

Check the matching yourself: run the self-check against hand-worked examples. The sample lists are made up; no real maker or project is in them.
